# website automation thing

this script automatically fills out forms and stuff. made it because i was too lazy to do my homework assignments manually lol

## requirements
- python 3
- selenium

install with: `pip install -r requirements.txt`

## usage
run `python auto_form.py` and it should open chrome and do the thing

## warning
sometimes it breaks if the website changes their html structure so u might need to update the selectors

also dont use this for anything sketchy i just use it for school stuff
