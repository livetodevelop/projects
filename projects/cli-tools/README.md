# cli tools

random command line utilities i made because the built-in ones are boring

## tools included

### `textanim.py`
makes text animations in terminal. good for presentations or whatever.

```bash
python textanim.py "hello world"
```

### `colorpick.py`
picks random color palettes. uses hex codes.

```bash
python colorpick.py --count 5
```

### `qr-gen.py`
generates qr codes from text or urls

```bash
python qr-gen.py "https://example.com"
```

## requirements
see `requirements.txt`

install with `pip install -r requirements.txt`
