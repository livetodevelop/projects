# Web Projects

random web stuff i made. nothing fancy, just learning.

## projects

### **dark-mode-everything.css**
a CSS snippet that forces dark mode on any website. doesn't always work perfectly but helps when a site has no dark theme.

### **homework-tracker.html**
simple page to track assignments. stores everything in localStorage so it persists. has a "due soon" section that highlights stuff due in 3 days.

### **link-hub.html**
single page with all my important links. organized by category (school, gaming, social). added a search bar because I kept losing things.

### **countdown-timer.js**
reusable countdown timer for presentations at school. big numbers, changes color when under 1 minute.

## tech used

- HTML/CSS/JavaScript (vanilla, no frameworks)
- localStorage for saving data
- minimal design, didn't want to spend hours on styling

## notes

- none of these are hosted anywhere, just open the HTML files locally
- the dark mode CSS works best on simple sites, complex ones break it
- homework tracker exported my data once before clearing localStorage, learned that lesson the hard way
