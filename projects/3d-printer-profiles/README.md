# 3D Printer Profiles (Flashforge Adventurer 5M)

slicers i use for my FF A5M. 0.4mm nozzle + textured PEI plate.

## profiles included

- **pla-basic** - everyday prints, 0.2mm layer height
- **petg-strong** - functional parts, needs higher temp
- **abs-ish** - tried ABS once, warping was crazy, switched to ASA
- **support-heavy** - for models with lots of overhangs

## notes

- textured PEI sticks REALLY well, let bed cool before removing prints or you'll bend the plate
- 0.4mm nozzle = 0.45mm extrusion width usually works best
- first layer speed at like 20mm/s or it won't stick
- don't trust the automatic leveling 100%, still need to tweak Z-offset

these are just my settings, your mileage may vary. also i'm not responsible if these profiles wreck your printer lol
