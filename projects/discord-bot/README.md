# my discord bot

a bot i made for my server. it has some cool commands and stuff.

## setup
1. install dependencies: `npm install`
2. put your token in a `.env` file
3. run with `node index.js`

## commands
- `!ping` - checks if bot is online
- `!roll [max]` - rolls a dice (default 6)
- `!8ball <question>` - magic 8 ball
- `!serverinfo` - shows info about the server
- `!userinfo [@user]` - shows user info
