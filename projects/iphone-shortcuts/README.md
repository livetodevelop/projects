# iPhone Shortcuts (iOS 17)

collection of shortcuts I made for my iPhone 15. mostly automation stuff.

## shortcuts included

### **Homework Timer**
- starts a focus timer (25 min pomodoro)
- automatically sets Do Not Disturb
- plays a sound when done
- logs completed sessions to a note

### **Screenshot Cleanup**
- finds all screenshots older than 30 days
- shows them in a grid
- lets you delete the ones you don't need
- saves the rest to a "Keep" album

### **Price Tracker**
- copies price from Safari
- checks if it's below a threshold
- sends a notification if it's a good deal
- logs prices to Numbers spreadsheet

### **Quick Notes to Discord**
- takes text from clipboard
- adds timestamp
- sends to a Discord webhook
- clears clipboard after

### **Bedtime Routine**
- sets alarm for 7 AM
- turns on Do Not Disturb until morning
- dims screen to minimum
- starts sleep sounds (white noise)
- locks all social media apps until morning

## installation

1. download the `.shortcut` files
2. open each one on your iPhone
3. tap "Add Shortcut"
4. configure any API keys/webhooks in the settings

## notes

- some shortcuts need permissions (notifications, photos, etc.)
- the Discord ones need a webhook URL (DM me if you want to know how to set that up)
- iOS updates sometimes break things, might need to fix actions
