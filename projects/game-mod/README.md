# minecraft mod thing

a simple mod i made for minecraft 1.20.1 using forge. adds some custom items and stuff.

## features
- adds a "super pickaxe" that mines faster
- adds a custom ore called "shadow ore" that spawns underground
- adds some armor made from shadow material

## installation
1. install forge for minecraft 1.20.1
2. download the .jar file (need to build it first)
3. put it in your mods folder

## building
run `gradlew build` and check `build/libs/` for the jar file
